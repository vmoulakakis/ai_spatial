# FitSpace AI — Project rules

Canonical repository: vmoulakakis/ai_spatial. Exclusively Spatial Intelligence.

## In scope
Guided multi-angle photography, CV spatial estimation, real-world scale calibration, editable measurements, constraint solving, revision-safe recomputation, 2D/3D, physical product fit, private multi-tenant API and optional native AR.

## Out of scope
Awin, Linkwise, advertiser applications, merchant feeds, offer prices, affiliate links, sales funnels, checkout, and commercial publishing. Those remain exclusively in their own projects. Do not edit any other repository as part of this project.

## Contract
- Apply vmoulakakis/Myagenticteam universal-creation-orchestrator and ADLC, plus web-design-intelligence, ui-craft-quality and agent-runtime as relevant.
- No made-up measurements or accuracy percentages. A calibration anchor or supported depth reading is required for real metric fit assertions.
- Make every geometry measurement editable and preserve confirmed anchors, source and uncertainty.
- After any measurement change recompute canonical geometry, 2D, 3D and physical-fit verdict. Resolve conflicting anchors visibly; support undo/redo.
- Prevent stale AI responses overwriting newer user corrections. All AI suggestions must be version checked.
- Keep photo/video uploads private, consented, tenant-isolated, deletable and never in this public repository.
- Use PRs and ADLC evidence for meaningful implementation; run actual tests and visual/device QA before claiming completion.

Status: specification transfer only; no working scanner or deployed spatial engine verified yet.
